# NORTE.INTERCAMBIOS
uma plataforma de planejamento de intercâmbio acessível. Não uma agência de turismo. O produto não vende pacote, vende o caminho: quanto guardar por mês, qual destino cabe no bolso, quais bolsas e programas existem como Workaway. A monetização vem de assinatura mensal barata mais parcerias com escolas de idiomas e seguros de viagem.
